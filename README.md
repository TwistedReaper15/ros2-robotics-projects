# ROS2 Robotics Projects

This repository contains beginner to intermediate robotics projects using ROS2.

## 🔧 Projects Included
1. TurtleBot3 Navigation (Coming Soon)
   - Simulated robot movement using Gazebo
   - SLAM and path planning with ROS2

2. Sensor Fusion Node (Coming Soon)
   - Fusing IMU and GPS sensor data
   - Publishing estimated pose

## 🧠 Goals
- Learn ROS2 (Foxy/Humble)
- Build practical robotics simulations
- Understand robotic sensors and movement

## 🔧 Tech Stack
- ROS2
- Gazebo
- Rviz2
- Python
